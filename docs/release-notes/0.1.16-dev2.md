# Dynamic Island 0.1.16-dev2 · Sports lag, no lone dash, reset all settings

**Development pre-release** · Changes since **0.1.16-dev1** · **English** / [한국어](#한국어)

## Fixes (attempts, not confirmed on a real device)

- **Lag in the notification panel and on the lock screen while a Google sports match is live.** System UI's notification decorators register a layout callback that removes itself through the view's current observer. When that is not the observer that is dispatching, the removal misses, the callback stays and more of them pile up, so every layout pass redoes work for as long as the match runs. The removal is now sent to the observer that is dispatching, for those decorators only. The diagnostics report has a new **shade layout callbacks** line with the number of repairs; if it stays at 0 during a live match, the decorator was not recognised and the line names the other listeners it saw removed on the wrong observer.
- **No lone dash on a match that has not started.** A Google sports pill or card whose score is only a dash now shows just the two team logos.
- **Frosted music card corners in the notification panel.** One UI's media player view clips its own drawing to a circular round rect before anything inside it is painted, which cut the corners of the Frosted card. That stock round clip is now off while the card draws, and System UI can no longer switch a row's outline clip back on under a Frosted card. The diagnostics report gets **shade material corner clip** and **shade material clip** lines.

## New options

- **Reset all settings.** A row under Advanced & troubleshooting, with a confirmation, clears every setting of the module, including the rules and app lists.
- **Charging card as text lines.** Under Events, next to Charging details: the charging card shows its figures as text lines instead of the gauge. The idea comes from @Bonki (#36); this version was written again on top of the current code.

## Validation and installation

- 259 default Android tests, the translation-tool tests, the 698-string catalogs and APK assembly pass locally. Behaviour was checked in headless tests and renders, **not on a real device**.
- Please test with a Google sports live notification and send the report of **Tools → Diagnostics**, especially the **shade layout callbacks** line.
- Install over dev1 (same signing key) and restart System UI or reboot.

## 한국어

**0.1.16-dev1 이후 변경사항을 모은 개발 프리릴리즈입니다.**

### 고친 것 (시도한 수정이며 실제 기기에서는 확인되지 않았습니다)

- **구글 스포츠 경기가 진행 중일 때 알림창과 잠금화면이 버벅이는 문제.** System UI의 알림 장식기는 스스로 지워지는 레이아웃 콜백을 등록하는데, 지울 때 뷰의 현재 옵저버를 거칩니다. 그것이 콜백을 실제로 전달 중인 옵저버가 아니면 제거가 빗나가 콜백이 남고 계속 쌓여서, 경기가 진행되는 동안 레이아웃 때마다 일을 다시 합니다. 이제 해당 장식기에 한해 제거를 전달 중인 옵저버로 보냅니다. 진단 리포트에 수리 횟수를 보여 주는 **shade layout callbacks** 줄이 생겼습니다. 경기 중에도 0에 머문다면 장식기를 알아보지 못한 것이고, 그 줄에 엉뚱한 옵저버에서 지워진 다른 리스너가 적힙니다.
- **시작 전 경기에 홀로 남던 대시(-) 제거.** 점수가 대시뿐인 구글 스포츠 알약과 카드는 이제 두 팀 로고만 보여 줍니다.
- **알림창의 프로스트 음악 카드 모서리.** One UI의 미디어 플레이어 뷰가 안에 무엇을 그리기 전에 먼저 자기 캔버스를 원형 둥근 사각형으로 잘라서 프로스트 카드의 모서리가 잘렸습니다. 이제 카드가 그리는 동안에는 이 기본 클립이 꺼지고, System UI가 프로스트 카드 아래의 행 윤곽 클립을 다시 켜는 것도 막았습니다. 진단 리포트에 **shade material corner clip**과 **shade material clip** 줄이 생깁니다.

### 새로운 옵션

- **모든 설정 초기화.** 고급 및 문제 해결 페이지의 행이며, 확인 대화상자 뒤에 규칙과 앱 목록을 포함한 모듈의 모든 설정을 지웁니다.
- **충전 카드를 텍스트 줄로.** 이벤트 페이지의 충전 상세 정보 옆 옵션입니다. 충전 카드가 게이지 대신 수치를 텍스트 줄로 보여 줍니다. 아이디어는 @Bonki(#36)에게서 왔고, 현재 코드 위에서 다시 작성했습니다.
