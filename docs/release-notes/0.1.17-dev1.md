## English

This pre-release includes the incoming-call banner fix and the accumulated bug fixes since 0.1.16.

- **Incoming calls open as a banner.** The caller and answer/decline buttons appear automatically in classic and iMotion modes, independently of ordinary card auto-open settings. The banner stays open while ringing and folds when the incoming call ends. Manual dismissal is respected.
- **Samsung call popups.** Extended the existing mini-window hide retries to cover a window created later. Matching SystemUI banners are suppressed while the island displays the call. Duplicate native/OA call cards are removed by notification identity. Answer, decline and speaker actions are selected by meaning rather than button order; other dialers use their own speaker actions.
- **Settings and custom rules.** Resetting all settings now reaches SystemUI. External access to the settings provider is restricted to the app and SystemUI. Rule changes no longer depend on hash equality; stage limits, highest-stage matching, labels-only imports, case-insensitive reset, colour reset and the 40-rule limit are consistent. Pattern merging preserves backreferences and the slow-regex guard handles nested wrappers. Separate orders keep separate cards, and waiting cards advance when displayed cards expire.
- **Notifications and replies.** Frequent progress updates no longer postpone refresh indefinitely. Action-only updates are applied. Recording replacement hides only the matching notification, and an app-opening intent is no longer assumed to stop recording. New messages with repeated wording are recognized correctly. Delayed banner removal cannot remove a newer posting under the same key. Failed replies keep their draft; charging popups do not discard an active reply. Choice-only replies use the app's own UI instead of sending arbitrary text.
- **OTP, progress and privacy.** Alphanumeric codes retain their letters and are marked copied only after clipboard success. Progress parsing handles shared capacity units, remaining percentages and configured context windows consistently. Live indeterminate progress remains visible. App exclusions follow the documented OTP/live-activity exceptions. Camera/microphone expiry is independent of location updates, and sensor state is separated by UID/profile. Original progress notifications remain available while the overlay is suppressed.
- **Music and connected devices.** Buffering at zero speed does not advance the playback clock; ended sessions freeze at their current position. Album-art history is isolated per session. Headphone battery updates refresh the card, remote sessions do not inherit phone headphones, and Bluetooth identity uses route addresses before display names. Audio visualization retries temporary initialization failures and releases partially created effects.
- **Device status and time.** Stale charging estimates expire, signed current measurements retain net-discharge direction, the first flashlight-off event after startup is recognized, and brightness is synchronized when the torch camera changes. Hotspot time includes deep sleep; paused stopwatches do not grow on notification reposts, and chronometers use elapsed time through clock corrections. Broken custom notification views can recover on a later update. Existing cards no longer auto-open again merely after returning from an app.

### Validation and installation

435 automated Android tests, release lint, translation validation and APK assembly passed. Physical-device integration of the latest fixes is still pending. Samsung's mini-window uses the existing close-after-creation API, so a brief initial appearance may remain.

Install over the existing version, then restart SystemUI or reboot. This APK uses the existing project release signature and a higher version code. Existing settings and the classic material default are retained.

## 한국어

수신 전화 배너 수정과 정식 0.1.16 이후 누적된 버그 수정을 포함한 프리릴리즈입니다.

- **수신 전화 자동 배너.** 일반·iMotion 모두 발신자와 받기·거절 버튼을 자동으로 펼칩니다. 일반 카드 자동 열기 설정과 별개로 동작하며, 벨이 울리는 동안 유지하고 수신 상태가 끝나면 접습니다. 사용자가 직접 닫은 경우는 존중합니다.
- **삼성 통화 팝업과 버튼.** 늦게 생성되는 미니 창까지 닫도록 기존 숨김 재시도를 연장했습니다. 아일랜드에 해당 전화가 표시되는 동안 기본 SystemUI 배너를 억제하고, 같은 알림의 중복 통화 카드를 제거합니다. 받기·거절·종료·스피커 버튼을 순서가 아닌 의미로 구분하며 다른 전화 앱의 스피커 액션도 사용합니다.
- **설정·사용자 규칙.** 전체 초기화를 SystemUI에도 반영하고 설정 제공자 접근을 앱과 SystemUI로 제한했습니다. 규칙 변경의 해시 충돌, 단계 상한·판정 순서, 이름만 있는 파일 가져오기, 대소문자 초기화, 색상 초기화와 40개 제한을 수정했습니다. 정규식 병합 시 역참조를 유지하고 위험 패턴 검사를 보강했습니다. 서로 다른 주문은 별도 카드로 처리하며 앞 카드가 만료되면 대기 카드를 올립니다.
- **알림·답장.** 빈번한 진행률 갱신으로 화면 업데이트가 계속 밀리는 문제와 버튼만 바뀐 갱신 누락을 수정했습니다. 녹화 원본은 해당 알림만 숨기고, 단순 앱 열기 인텐트를 중지 버튼으로 잘못 연결하지 않습니다. 같은 문구의 새 메시지와 동일 키의 새 게시를 구분합니다. 답장 전송 실패나 충전 팝업 때문에 초안을 잃지 않으며 선택형 답장은 앱에서 처리합니다.
- **인증번호·진행률·개인정보 표시.** 영숫자 인증번호의 문자를 보존하고 복사 성공 시에만 완료 표시를 합니다. 용량 단위·잔여 비율·문맥 범위 해석과 실시간 로딩 표시를 수정했습니다. 앱 제외는 안내된 인증번호·라이브 활동 예외를 따릅니다. 위치 갱신이 카메라·마이크 종료를 미루지 않으며 UID·프로필별 센서 상태를 분리합니다. 아일랜드가 숨겨졌을 때 원본 진행 알림까지 숨기지 않습니다.
- **음악·연결 장치.** 버퍼링 중 재생 시간 증가와 세션 종료 시 시간 역행을 수정하고 앨범 아트를 세션별로 분리했습니다. 이어폰 배터리 갱신을 반영하며 원격 재생에 휴대폰 이어폰 정보를 붙이지 않습니다. 같은 이름의 블루투스 장치는 출력 주소를 우선합니다. 시각화 초기화 실패 후 자동 재시도와 자원 정리도 보완했습니다.
- **기기 상태·시간.** 오래된 충전 추정값을 버리고 실제 전류의 방전 방향을 보존합니다. 시작부터 켜져 있던 손전등의 첫 끄기 알림과 플래시 카메라 변경 시 밝기 동기화를 수정했습니다. 핫스팟 시간에 절전을 포함하고, 스톱워치 재게시와 시스템 시각 보정으로 경과 시간이 바뀌는 문제를 수정했습니다. 오류 난 커스텀 알림의 복구와 앱에서 돌아올 때 기존 카드가 다시 자동으로 펼쳐지는 문제도 수정했습니다.
